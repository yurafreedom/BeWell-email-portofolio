# BeWell Alert — Lifecycle Email System

Static portfolio microsite for GitHub Pages. No build step or dependencies.

## Included
- 16 lifecycle emails
- 1 lead-magnet guide
- responsive 3/2/1-column portfolio grid
- category filters
- animated side drawer with the original HTML email
- standalone email links

## Publish on GitHub Pages
1. Create a new public repository, e.g. `bewell-email-case-study`.
2. Upload the **contents** of this folder to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select `main` and `/ (root)`, then Save.
6. GitHub will publish the site at `https://<username>.github.io/<repo>/`.

## Notes
- The portfolio intentionally excludes the three unnumbered `template-1/2/3.html` working files from the source archive.
- Existing email images are referenced from their current remote URLs, so those assets must remain available for the original emails to render fully.
- No performance or revenue metrics are claimed because they were not part of the supplied project materials.
